# Architecture starter

`architecture-starter.drawio` is a native editable, uncompressed example. It
demonstrates nested containers, service cards, a third-party logo, parallel
request/callback rows, and short labeled connectors. All names, relationships,
ownership boundaries, and page dimensions are illustrative and replaceable.

The two Cosmos cards represent different example stores, not two views of a
single deployed component. Real diagrams should use actual store names and
deployment topology.

Azure icons reference the Draw.io Azure library at `app.diagrams.net`; rendering
them requires network access. Microsoft owns the Azure product marks. The
embedded Stripe glyph uses the Simple Icons Stripe path (CC0, from
https://github.com/simple-icons/simple-icons); the Stripe mark remains a Stripe
trademark. Use of a logo does not imply endorsement. No project-specific host,
invoice, customer, or implementation detail is bundled in this template.

This template is a style seed, not a screenshot-based guarantee of a renderer's
text metrics. Follow the visual review loop after adapting it.
